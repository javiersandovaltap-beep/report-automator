# CLAUDE.md

Read AGENTS.md first.

Before modifying files:
1. Summarize what the project actually does.
2. State which files you will inspect.
3. Propose a short plan.
4. Wait for confirmation before making large changes.

Collaboration rules:
- Make small, specific changes.
- Explain your assumptions.
- If you infer something from file names, state it as a hypothesis and then verify it.
- Do not mix analysis, redesign, and execution in a single step.
- After each change, summarize what you did and how to verify it.
